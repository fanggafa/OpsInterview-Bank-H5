## 图类型与画法

| 类型 | 数量 | 画什么 |
|---|---|---|
| **架构** | 8 | 组件方块 + 连线，画出「谁连谁、数据往哪流」 |
| **流程** | 4 | 竖向步骤箭头，画出「先后顺序与阶段边界」 |
| **状态** | 2 | 状态圆 + 迁移箭头，画出「什么条件切到哪个状态」 |
| **分层** | 2 | 上下堆叠的层带，画出「每层归属与对应关系」 |
| **原理** | 7 | 带标注的示意图，画出「机制怎么运作」 |
| **结构** | 4 | 分栏或嵌套结构，画出「组成部分与归属」 |

## 筛选标准

只保留**表格表达不了的空间/顺序关系**：

- ✅ 保留：**架构**（组件连接）、**流程**（步骤先后）、**状态**（状态迁移）、
  **分层**（层级归属）、**原理**（机制运作）、**结构**（组成关系）
- ❌ 剔除：**纯「区别/对比」题** —— 这些题的答案里**已经有对比表格**，
  表格本身就把差异说清楚了，再画一张「左右并列」的图属于信息重复

另外剔除：开放式经验题（「你会怎么做」「如何沉淀」），这类没有可画的结构。

## 插图规范（与现有 340 张图一致）

- inline SVG，`viewBox="0 0 340 H"`，宽度固定 340
- 字号下限 **7px**；颜色用 `--fig-node-a/b/c/d`、`--fig-text`、`--fig-muted`
- 答案里用 `[[图:figure-id]]` 引用
- `npm run check:figures` 会校验越界、文字重叠、行距过紧
